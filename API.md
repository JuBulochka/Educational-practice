# REST API каталога

Базовый адрес при локальном запуске — `http://127.0.0.1:8000/api/`.

| Метод и маршрут | Доступ | Результат |
|---|---|---|
| `GET /categories/`, `GET /categories/{id}/` | Все | Список и карточка категории |
| `POST /categories/`, `PATCH/PUT/DELETE /categories/{id}/` | Сотрудник | Создание, изменение, удаление категории |
| `GET /categories/{id}/services/` | Все | Список услуг выбранной категории |
| `GET /services/`, `GET /services/{id}/` | Все | Список и карточка услуги, включая `category_name` |
| `POST /services/`, `PATCH/PUT/DELETE /services/{id}/` | Сотрудник | Создание, изменение, удаление услуги |
| `POST /requests/` | Все | Отправка заявки, HTTP 201 |
| `GET /requests/`, `GET /requests/{id}/` | Сотрудник | Просмотр заявок |
| `GET /statistics/` | Сотрудник | Количество услуг в каждой категории и заявок со статусом `new`, созданных на текущей неделе |
| `GET /auth/session/` | Все | Текущий сотрудник или `null`, токен CSRF |
| `POST /auth/login/` | Все, с CSRF | Вход сотрудника, обновлённый токен CSRF |
| `POST /auth/logout/` | Сотрудник, с CSRF | Завершение сессии, HTTP 204 |

Сотрудник — активная учётная запись Django с флагом `is_staff`. Посетителям доступны только опубликованные услуги (`is_available=true`), включая запрос по прямой ссылке. Сотрудники видят все записи. Заявки обрабатываются через Django Admin.

## Список услуг

`GET /services/?category=2&is_available=true&min_price=1000&max_price=2200&search=Excel&ordering=price&page=1`

Фильтры применяются одновременно. `category` — ID категории. Для цены доступны `ordering=price` и `ordering=-price`. Поиск работает по названию и описанию. Пагинация возвращает `count`, `next`, `previous`, `results` по 6 записей. Неверные значения фильтров и параметров возвращают 400, несуществующая страница — 404.

## Создание заявки

```json
{
  "service_id": 1,
  "client_name": "Иван Петров",
  "phone": "+79990000000",
  "desired_at": "2099-12-01T14:30:00+03:00"
}
```

Ответ содержит номер `id`, сведения заявки и серверный статус `new`. Несуществующая или недоступная услуга, прошедшая дата и пустой телефон дают 400 с ошибкой соответствующего поля. Удаление услуги с заявками или категории с услугами даёт 409.

## Вход сотрудника

Запросите `GET /auth/session/` с cookie и передайте полученный `csrfToken` в заголовке `X-CSRFToken` при отправке `{ "username": "...", "password": "..." }` на `POST /auth/login/`. Сохраните cookie-сессию и используйте обновлённый токен в заголовке для операций записи и выхода. Запрещённые операции с сессионной авторизацией дают 403.
