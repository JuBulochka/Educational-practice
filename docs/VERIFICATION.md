# Проверка каталога услуг

## Задание № 1

На чистой SQLite применены все миграции. После двух запусков `seed_catalog` в базе 4 категории, 15 услуг и 8 заявок. Публичный список вернул HTTP 200 и 14 опубликованных услуг. В управлении доступна и пятнадцатая, закрытая для записи.

**20 автоматизированных тестов Django REST Framework прошли.** Проверены список, поиск по названию и описанию, пагинация, сортировка, сочетание фильтров, карточка, маршрут категории, права на категории и услуги, ограничения цены и длительности, сессия и CSRF, конфликты удаления, статистика, заявки и проверка входных данных.

## Задание № 2

Проверки выполнены в Microsoft Edge с запущенными Django и React. В сценарии 8 браузер тестово подставлял ответ HTTP 500 для списка услуг. После снятия подстановки кнопка «Повторить» загрузила реальные данные Django.

| № | Сценарий | Результат |
|---:|---|---|
| 1 | Открыть каталог и карточку, обновить страницу карточки | Данные загружаются, прямой маршрут сохраняется |
| 2 | Совместить категорию, доступность, диапазон цены, сортировку и поиск | Все параметры переданы вместе, поиск по кириллице работает без учёта регистра, запрос отложен на 350 мс, пустое состояние и сброс работают |
| 3 | Перейти на вторую страницу | Сервер возвращает следующие 6 услуг |
| 4 | Открыть несуществующую услугу | HTTP 404 и ссылка назад в каталог |
| 5 | Отправить форму с прошедшей датой | HTTP 400, ошибка рядом с датой, введённые данные сохранены |
| 6 | Отправить корректную заявку | HTTP 201, показан номер от сервера, кнопка блокируется до ответа |
| 7 | Войти сотрудником, создать, прочитать, изменить и удалить услугу, затем выйти | Сессия переживает обновление, меняются цена, категория и доступность, отмена удаления сохраняет запись, подтверждение удаляет её |
| 8 | Получить HTTP 500 и повторить загрузку | Появляется сообщение, повторный запрос восстанавливает список |
| 9 | Сохранить услугу в избранное, обновить страницу и убрать её | Избранное сохраняется в браузере как список ID |
| 10 | Открыть каталог, карточку, форму и управление на 390 px | Горизонтальной прокрутки нет. Управление проверено до и после входа |

Также проверена ширина 1280 px и выполнена сборка `pnpm build`.
